1) Drop letter_patch.exe in "\steamapps\common\BatenKaitos HD Remaster\Batenkaitos2\".
2) Run the executable.
3) The patched global-metadata.dat and GameAssembly.dll files will be created in a newly created patch folder.
4) Create a backup of the original global-metadata.dat and GameAssembly.dll files in a different location or with a new name.
5) Move the patched global-metadata.dat to "\steamapps\common\BatenKaitos HD Remaster\Batenkaitos2\Batenkaitos_Data\il2cpp_data\Metadata\".
6) Move the patched GameAssembly.dll \steamapps\common\BatenKaitos HD Remaster\Batenkaitos2\

The MD5 checksum of the patched metadata file should be 0x8C0CBA29002B300A5BE0DD4C799DD5FD
The MD5 checksum of the patched dll file should be 0x190276A42FF273CC08854D063079CDE2
